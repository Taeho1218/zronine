# 프로필 커버 사진

여기에 사진 파일 하나를 넣으면 마이페이지 / 프로필 페이지의 커버가 그 사진으로 바뀝니다.

- 지원 형식: png, jpg, jpeg, webp, avif (대문자 확장자도 됩니다)
- 파일 이름은 자유입니다. 여러 장이 있으면 이름 순으로 첫 번째를 씁니다.
- 비워두면 지금처럼 브랜드 색 그라데이션이 깔립니다.
- 권장 크기: 가로 1920px 이상, 세로 400px 이상 (아래쪽에 이름이 얹히므로
  아래 1/3 에 중요한 피사체가 없는 사진이 좋습니다)

서버가 `coverImageUrl` 을 내려주기 시작하면 그 값이 이 파일보다 우선합니다.
