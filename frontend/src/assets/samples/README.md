# 데모용 상품 이미지

목업 모드(`VITE_USE_MOCK=true`)에서 카드/상세 화면에 미리 채워 보여줄 이미지를 여기에 둔다.

## 넣는 법

**파일을 이 폴더에 넣기만 하면 된다. 코드는 고치지 않는다.**

```
post-1.png      ← 대표 (카드 썸네일 / 상세 첫 화면)
post-1-2.jpg    ← 추가 이미지
post-1-3.webp
post-2.png      ← 다른 글의 대표
```

`src/api/sampleImages.js` 가 이 폴더를 통째로 훑어 `post-1`, `post-1-2`, `post-1-3` … 순서로 묶어준다.

- **확장자는 아무거나 된다** — png, jpg, jpeg, webp, avif, gif 를 섞어 써도 되고 코드에 적지 않는다.
- **장수도 자유다** — 대표 한 장만 넣어도 되고, `-2`, `-3` … 을 붙여 계속 늘려도 된다.
- 두 장 이상이면 상세 화면에 **썸네일 줄**과 `2 / 5` 위치 표시가 생긴다. 한 장이면 나오지 않는다.
- 피드 카드에는 항상 대표(접미사 없는 파일) 한 장만 쓴다.

## 어느 글에 붙는지

`src/api/mock.js` 의 각 글이 `sampleSet('post-1')` 처럼 이름 앞부분만 지정한다.

| 파일 이름 | 글 |
| --- | --- |
| `post-1*` | 바이오던스 클렌징&겔패드 (GB-001) |
| `post-2*` | 콜롬비아 수프리모 |
| `post-3*` | 디카페인 스위스워터 |
| `post-4*` | 브라질 산토스 블렌드 |
| `post-5*` | 저당 그래놀라 |
| `post-6*` | 공구 후기 (일반글) |

## 파일이 없어도 괜찮다

한 장도 없으면 해당 글은 원래의 파스텔 자리표시자로 나온다. 깨진 이미지 아이콘은 뜨지 않는다.
그래서 이미지를 모으는 대로 하나씩 넣어도 화면이 망가지지 않는다.

## 주의

여기 있는 건 화면 확인용 더미다.
`VITE_USE_MOCK=false` 로 실서버에 붙으면 이 폴더는 쓰이지 않고 서버가 준 이미지 URL 이 그대로 나온다.
