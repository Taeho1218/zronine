# 데모용 상품 이미지

목업 모드(`VITE_USE_MOCK=true`)에서 카드/상세 화면에 채워 보여줄 이미지를 여기에 둔다.

## 넣는 법

**파일을 이 폴더에 넣기만 하면 된다. 코드는 고치지 않는다.**

이름은 아래 두 가지 중 아무거나 쓰면 된다. 둘 다 있으면 공구 코드 쪽이 우선한다.

| 이름 규칙 | 예 |
| --- | --- |
| 공구 코드 | `gb-002.png` |
| 글 번호 | `post-2.png` |

- **확장자는 자유** — png, jpg, jpeg, webp, avif, gif 를 섞어 써도 된다.
- **대소문자도 자유** — `GB-002.PNG` 도 잡힌다.
- 파일을 나중에 다른 이름으로 바꿔도, 위 규칙만 지키면 코드를 손댈 필요가 없다.

## 한 글에 여러 장

뒤에 `-2`, `-3` 을 붙인다. 확장자는 서로 달라도 된다.

```
gb-002.png       ← 대표 (카드 썸네일 / 상세 첫 화면)
gb-002-2.jpg
gb-002-3.webp
```

두 장 이상이면 상세 화면에 **썸네일 줄**과 `2 / 3` 위치 표시가 생긴다. 한 장이면 나오지 않는다.
피드 카드에는 항상 대표(접미사 없는 파일) 한 장만 쓴다.

## 완전히 다른 이름을 쓰고 싶다면

`src/api/mock.js` 의 해당 줄에 `image` 만 덧붙이면 그 이름이 최우선이 된다.

```js
{ code: 'GB-002', ..., image: '롱비다커큐민' },   // → 롱비다커큐민.png
```

## 어느 글에 붙는지

`mock.js` 의 `SHEET` 배열 순서가 곧 글 번호다. 공구 코드와 번호가 1:1로 맞는다.

| 파일 | 글 |
| --- | --- |
| `gb-001*` 또는 `post-1*` | 바이오던스 클렌징&겔패드 |
| `gb-002*` 또는 `post-2*` | 롱비다 커큐민 복합체 |
| … | … |
| `gb-033*` 또는 `post-33*` | 자떙 닭발 |

## 파일이 없어도 괜찮다

한 장도 없으면 그 자리에 브랜드 마스코트가 대신 나온다. 깨진 이미지 아이콘은 뜨지 않는다.
그래서 이미지를 모으는 대로 하나씩 넣어도 화면이 망가지지 않는다.

## 주의

여기 있는 건 화면 확인용 더미다. 브랜드 로고·마스코트 같은 UI 자산은 `src/assets/brand/` 에 있다.
`VITE_USE_MOCK=false` 로 실서버에 붙으면 이 폴더는 쓰이지 않고 서버가 준 이미지 URL 이 그대로 나온다.
